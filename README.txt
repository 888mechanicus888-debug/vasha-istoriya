# ВАША ИСТОРИЯ — готовый статический сайт

Файлы:
- index.html — страница и все блоки дизайна
- styles.css — адаптивный дизайн
- script.js — мобильное меню, модальные карточки и заявка в Telegram
- assets/ — точные присланные изображения

Запуск:
1. Распаковать архив.
2. Загрузить содержимое на хостинг в public_html / www.
3. Открыть index.html через домен.
